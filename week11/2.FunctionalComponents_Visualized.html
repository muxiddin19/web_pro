Functional Components

A functional component is a JavaScript function that returns JSX. Its name must start with a capital letter.

1. A minimal component, used like an HTML tag

Code
// Minimal component: a plain JS function
function Greeting() {
  return <h2>Hello, World!</h2>;
}

// Arrow function syntax: also valid
// (use ONE of the two, not both)
// const Greeting = () => <h2>Hello, World!</h2>;

function App() {
  return (
    <div>
      <Greeting />
      <Greeting />
    </div>
  );
}

2. Why the capital letter matters

Code
function Demo() {
  return (
    <div>
      <Greeting />   {/* calls your function */}
      <greeting />   {/* NOT your function */}
    </div>
  );
}
Result (live)
HTML the browser gets
...
Capital letter matters. <Greeting /> calls your function. <greeting /> is treated as a built-in tag name. React creates an empty element called <greeting> and prints a warning in the browser console (press F12 to see it). Always capitalize component names.

3. Returning several elements: Fragment vs wrapper div

With a Fragment <>...</>, no extra element is added to the page.

With a Fragment
function UserCard() {
  return (
    <>
      <h3>Zulfiya Karimova</h3>
      <p>Computer Engineering · Year 3</p>
    </>
  );
}
