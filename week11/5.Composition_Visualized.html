Component Composition

Build a complex UI from small components that each do one job.

1. Small pieces, composed together

Code
function Avatar({ src, alt }) {
  return <img src={src} alt={alt}
    style={{ borderRadius: '50%', width: 48 }} />;
}

function Badge({ text, color = '#0891b2' }) {
  return (
    <span style={{ background: color, color: '#fff',
      padding: '2px 8px', borderRadius: 4 }}>
      {text}
    </span>
  );
}

function StudentCard({ name, studentId, year, avatarUrl }) {
  return (
    <div className="card">
      <Avatar src={avatarUrl} alt={name} />
      <h3>{name}</h3>
      <p>ID: {studentId}</p>
      <Badge text={`Year ${year}`} />
    </div>
  );
}

function App() {
  return (
    <div className="student-list">
      <StudentCard name="Amir" studentId="202011234"
        year={3} avatarUrl="/img/amir.jpg" />
      <StudentCard name="Zulfiya" studentId="202012345"
        year={2} avatarUrl="/img/zulfiya.jpg" />
    </div>
  );
}
Result (live, try the X-ray)
Component tree (static)
App
├─ StudentCard Amir
│   ├─ Avatar
│   └─ Badge
└─ StudentCard Zulfiya
    ├─ Avatar
    └─ Badge

Data flows down the tree as props: App gives StudentCard a name and year, and StudentCard passes pieces on to Avatar and Badge.

The live version adds a data-c attribute to each element, only so the X-ray checkbox can outline it. The avatar images are generated placeholders, because /img/amir.jpg does not exist here.

2. Reuse: the same pieces in other places

Code
// Same Badge, different props
<Badge text="Year 3" />
<Badge text="Required" color="#d93025" />
<Badge text="Online" color="#1a7f45" />
<Badge text="Elective" color="#8a9099" />

// Same Avatar, in a comment row
<div className="comment">
  <Avatar src={avatarUrl} alt="Amir" />
  <p>Great lecture!</p>
</div>
Result (live)
Why it works

Badge and Avatar know nothing about students. They only know how to draw themselves from their props.

Fix the Badge style once, and every badge in the app changes.

3. When to split a component

Before: one big component
function StudentCard(props) {
  return (
    <div className="card">
      <img src={props.avatarUrl}
        alt={props.name}
        style={{ borderRadius: '50%', width: 48 }} />
      <h3>{props.name}</h3>
      <p>ID: {props.studentId}</p>
      <span style={{ background: '#0891b2',
        color: '#fff', padding: '2px 8px',
        borderRadius: 4 }}>
        Year {props.year}
      </span>
    </div>
  );
}
// Avatar and badge styling is stuck
// inside. Can't reuse it elsewhere.
After: split by job
function StudentCard({ name, studentId,
                       year, avatarUrl }) {
  return (
    <div className="card">
      <Avatar src={avatarUrl} alt={name} />
      <h3>{name}</h3>
      <p>ID: {studentId}</p>
      <Badge text={`Year ${year}`} />
    </div>
  );
}
// Reads like an outline of the card.
// Avatar and Badge live on their own.
One job each (static)
ComponentIts one job
AvatarDraw a round picture
BadgeDraw a small coloured label
StudentCardArrange one student's info
AppLay out the list of cards
Single Responsibility Principle: if you can't describe a component's job in one short sentence, or you find yourself copying the same markup, it is time to split it.
